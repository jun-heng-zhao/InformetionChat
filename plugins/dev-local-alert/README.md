# dev.local-alert

本地测试提醒插件，用于验证 M1 的授权来源前台紧急弹窗。

## 职责

- 提供 `alert.notify-test@1.0.0`，由页面按钮或宿主界面触发。
- 登记两个通知类别：`local-test-alert`（请求上限 `critical`）与 `local-test-info`（上限 `normal`）。
- 不自行判断“是否紧急”，实际展示等级完全由宿主按用户策略与权限计算。

## 关键设计点

- 请求中不携带 `sourceId`，来源标识由宿主安装记录生成，插件无法冒充其他来源。
- 类别与等级上限在 manifest 中登记；未登记类别会被宿主拒绝，不能动态创建已授权的紧急来源。
- 未开启紧急授权的类别即使请求 `critical` 也会降级，降级原因随结果返回。
- 确认（acknowledge）只能由可信宿主界面完成，插件代确认会被拒绝。

运行方式见[开发环境与运行说明](../../docs/开发环境与运行说明.md)。
