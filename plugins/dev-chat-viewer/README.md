# dev.chat-viewer

聊天归档查看器插件，演示插件之间通过宿主服务契约互通。

## 职责

- 消费 `document.convert ^1.0.0`，自身不实现任何格式转换。
- 提供 `archive.export@1.0.0`，供自己的页面按钮触发；该服务内部通过 `host.service.call` 调用已绑定的转换提供者。
- `agentCallable: false`：本插件的导出操作未向 Agent 会话开放，派生用例验证了这一点。

## 关键设计点

- 输入通过 `host.file.pick` 获得只读句柄，不接收原生路径。
- 结果经 `host.resource.read` 读取，句柄由宿主在其与转换器之间派生，调用方拿不到提供者的内部对象。
- 实际完成转换的提供者安装 ID 会随结果回传，便于确认绑定未被悄悄更换。

运行方式见[开发环境与运行说明](../../docs/开发环境与运行说明.md)。
