# 开发文档索引

更新：2026-09-18。本文列出项目完整开发文档与契约清单，并标明用途与阶段。设计部分仍为草案；宿主核心与三个示例插件已有首个可运行实现，范围与限制见[开发环境与运行说明](开发环境与运行说明.md)。

范围以用户要求为准：个人开发者、无官方团队或基础服务；重点为插件加载、隔离、互通和复用；Agent 调用插件与前台紧急通知为简单目标。文档冲突按 ADR 0009 → ADR 0008 → 开发总文档 → 专项规范与契约处理。有效宿主原则已合并到当前 ADR 与专项规范，旧稿已清理。
