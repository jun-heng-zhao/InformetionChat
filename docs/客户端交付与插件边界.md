# 客户端交付与插件边界

文档版本：1.3-draft。按 [ADR 0008](adr/0008-solo-developer-delivery-baseline.md)执行。个人维护，没有官方账号、后台、认证或默认插件仓库。下表区分首版范围与目标配置，未通过实测的端不列为已支持。

## 1. 首版交付

首版先在一个桌面平台完成插件加载、隔离和服务互通，并通过简单 Agent 调用和前台紧急通知验证复用。Linux 为当前验证候选，若 WebView 选型无法满足隔离则调整运行时或转到 Windows 验证。M0 通过后才开放该端的外部插件入口。

M1 提供已安装列表、本地包导入、权限和来源展示、启停、卸载、手动更新及失败诊断。插件目录、网络下载、CLI 和热重载按后续阶段增加。标准文件/归档查看与结果保存支撑插件使用，不把完整聊天平台或数据管理平台作为前置条件。

随包模块与可选插件按实际声明和授权访问数据。格式转换按需安装；用户可以只使用本地包，无需发布者账号或证书。未签名可安装和操作系统是否要求应用签名分别处理。

## 2. 平台目标矩阵

| 能力 | M1 单桌面首版 | 桌面完整包目标 | 移动基础包目标 |
|---|---|---|---|
| 本地工作区、文件选择、基础查看、结果保存 | 提供 | 完善搜索、归档和备份 | 按系统选择器与分享接口适配 |
| 插件管理与互通 | 纯离线 UI 插件，本地已安装依赖 | 按需增加运行时、目录源与开发能力 | 仅启用经过渠道及隔离验证的能力 |
| Agent | 宿主运行时的本地授权适配器 | 扩充协议与操作类型 | 按进程与后台限制单独验证 |
| 紧急通知 | 已授权来源的应用前台弹窗 | 系统通知、后台接收按需适配 | 前台弹窗、后台按系统能力降级 |
| 多窗口、批量任务、CLI、热重载 | 后续 | 目标提供 | 正式包精简或省略 |
| WASM Worker、联网连接器 | 后续 | 验证后提供 | 运行时和渠道允许后再启用 |

四端共享接口语义，按阶段和运行时公布能力。平台声明只代表作者目标；实际支持名单要注明系统、架构、WebView 版本及验证日期。缺少硬件、构建工具链或分发资格的端保持未验证。

## 3. 首版使用流程

本地工作区 → 导入两个兼容离线插件 → 查看权限 → 绑定转换服务 → 选择一份输入 → 返回并保存结果。切换到 Agent 适配器后，可以在预授权范围内调用同一服务、查询和取消任务。测试插件发送本地紧急事件，宿主按来源授权显示前台弹窗。

首次断网可完成上述流程，必要的宿主组件与运行依赖应随包或通过离线安装步骤提供。Agent 测试可以使用本地脚本客户端，不要求模型账号或模型服务；真实 Agent 在应用之外的数据行为不由宿主控制。

归档导出包含消息与附件清单，不包含附件原文件、外部账号或权限。导入和备份规则见[本地数据规范](本地数据与备份恢复.md)。停用转换器不删除已保存结果；插件私有格式需插件自身的导出或交接方案。

## 4. 加载和兼容

M1 仅支持 `runtime.ui`、`connectivity: offline`。manifest 能表达 Worker、联网或其他平台，不意味着客户端支持。未知权限、必需能力缺失、来源冲突或不兼容依赖拒绝激活；可选能力缺失只隐藏相关入口。

本地包执行清单、路径、摘要、资源预算和授权校验。桌面测试目录先复制为受控快照，不能绕开检查。没有目录源时只显示本地管理入口，不显示已上线市场或审核状态。

后续联网连接器通过宿主代理访问用户授权目标。服务部署、账号、同步和推送属于接入方，应用不自动提供后台。具体网络能力以实测为准，不能用“中心化/去中心化兼容”替代协议实现。

## 5. 移动和通知限制

正式移动包不执行任意开发目录或下载的原生二进制。可加载的 Web 内容、插件资源及 UI 行为需逐渠道验证；iOS 构建与设备测试需要对应工具链和条件，不能仅凭 Flutter 代码编译说明可分发。

前台插件任务可取消，进入后台或被系统终止时记录中断；恢复时重新获取失效句柄。首版不要求移动插件常驻，后台通知也不依赖未经验证的轮询或免费推送中继。

紧急通知的 M1 承诺仅为：宿主运行且在前台、来源有授权、事件有效时展示弹窗。后台/锁屏/退出提醒列入后续平台适配，系统接受通知不等于用户看到。详见[通知规范](通知分级与紧急提醒.md)。

## 6. 验收和分发

- 断网完成插件加载、服务绑定、输入授权、结果保存；没有账号或远端源依赖。
- 两插件互访私有数据失败，明确授权的资源可传递；停用后旧会话和句柄失效。
- Agent 不点击插件页面即可发现、调用、查询和取消同一服务；越权返回明确错误。
- 授权紧急来源在前台弹窗；未授权、重复、撤回和过期事件正确处理。
- 卡死、超时或迁移失败可关闭插件并恢复数据，不使其他安装失去操作能力。
- 发布说明列明平台验证结果、构建命令、运行依赖、许可证、更新来源与已知限制；手动更新不扩大权限。
