# 插件目录与发布治理构想

状态：按 [ADR 0008](../adr/0008-solo-developer-delivery-baseline.md)分阶段实施。审核、上传发布、发布者认证、中心化签名/证书和撤回服务均不属于当前开发范围；本地安装只依赖结构、兼容性和权限检查。

按 [ADR 0008](../adr/0008-solo-developer-delivery-baseline.md)，M1 只交付本地安装管理，测试目录先复制为受控快照后加载。后续按需加入目录入口和用户配置的源，默认无预置源；目录元数据和包下载均不能获得执行或授权资格。源不可用不影响本地功能。

本地加载器校验清单、路径、运行时兼容性、依赖和用户权限。这些是程序执行前的结构与授权检查，不表示内容已经经过审核。插件作者信息是自述元数据，不代表身份认证或可信等级。

后续如需要社区目录、包托管或审核，再单独设计其治理方式。本地 SDK 和运行时不依赖其存在。
